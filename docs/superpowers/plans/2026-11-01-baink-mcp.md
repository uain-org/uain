## Approach decision

A blind native MCP reverse proxy would expose commands and misleading BAINK authority. Adding the SDK as a runtime dependency would require changing the current dependency-free immutable package. Choose a small stateless protocol boundary with an exact method/tool allowlist and actual SDK client verification. JSON-only request/response is permitted by the official2025-11-25 Streamable HTTP spec; GET returns405 (no SSE stream). Stateless cancellation notifications are accepted but cannot cancel a different POST; existing service deadlines and actual native-process caps remain the cost boundary. No sessions, subscriptions, background task or execution capability is advertised.

Rahul explicitly requested continued implementation using the saved plan and delegated routine decisions; no new product confirmation is needed for this bounded public-read scope.

## Review focus

- Unknown Host/Origin, proxy headers, noncanonical aliases, cross-site requests: deny before dispatch.
- Unknown/private tool, injected fields/URLs/keys, batches/oversize/deep/malformed requests: reject without mutation or echoing secrets.
- Unavailable or stale source: return explicit tool error/unavailable evidence, never successful empty opportunities or verified earnings.
- Concurrent requests and disconnects: bounded admission plus actual-job lifetime; no unlimited sessions or native spawning.
- Protocol/client compatibility and docs: initialize, negotiated version, notifications, list/call, resource/read, prompt/get tested with real SDK client.
