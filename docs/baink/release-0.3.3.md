## Behavior and limits

Profiles include a separate bounded native-committed historical research panel.
Public HTTP project IDs are discovery hints only. The pinned native verifier
proves member/import/project/work records; proof chain/epoch/verifier/address/key
and matching snapshots are checked before publication. At most four instances,
four projects and eight indexed works are discovered. Foreign or unavailable
records do not become an empty complete history. No private BAINK metadata is used.

Work comes from frozen `legacy/work/` imports. Later mutable `legacy_work/`, claim
revision and arbitration updates are outside this view. Each row says Imported
state. Distinct checker members are counted, separately from checker instances;
recorded original confirmed/new checks are not a fresh novelty review. No AI$
payment, earned balance, operator vetting or private project role is established.
Member licence/proof freshness is current to the header, with expiry clearing the
panel until explicit refresh. Anonymous unpublished profiles continue to stop
before native reads; signed-in discovery can review the native member record.

API: `GET /api/members/:nativeAddress/native-record`, public, no query fields.
A null-prototype query parser preserves unsupported `__proto__` keys for rejection.
Public Project labels now describe UAIN source records, which can include imported
history. No style or landing design changes. Unchosen design proposals stay local.
