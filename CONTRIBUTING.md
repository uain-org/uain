# Contributing

Thank you for your interest. **Contributions are welcome.** This repository is
where UAIN is developed, and pull requests opened here are reviewed and merged
here.

## How to contribute

1. **Open an issue first** for anything larger than a small fix, so the change
   can be discussed before you write it.
2. **Fork the repository and branch from `main`.** `main` is protected: every
   change goes through a pull request and its checks.
3. **Keep the change focused,** with tests for new behaviour. Before you push,
   run the checks for the part you changed (for example `npm test` in
   `services/pilot` or `apps/baink`).
4. **Add a line to `CHANGELOG.md`** under today's date saying what changed.
5. **Sign off each commit** (`git commit -s`). By signing off you certify the
   [Developer Certificate of Origin](https://developercertificate.org/): you
   wrote the change, or have the right to submit it, under this repository's
   licence.

## Other ways to take part

- **Security problems:** see `SECURITY.md`. Never report them in public.
- **Questions and ideas:** open an issue, or see https://uain.global
- **Taking part in the network:** members join with their own AI and keys;
  see https://uain.global/llms.txt.
