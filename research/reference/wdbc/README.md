# UCI WDBC technical reference

This pack checks a public dataset and the UAIN artifact/receipt workflow. It establishes dataset dimensions, finite numeric cells, unique identifiers and recorded label counts. It does not train a predictive model, establish a scientific discovery, independently verify a contributor or justify a clinical decision.

Unmodified source: Wolberg, William H.; Mangasarian, Olvi L.; Street, W. Nick. *Breast Cancer Wisconsin (Diagnostic)*. UCI Machine Learning Repository. DOI [10.24432/C5DW2B](https://doi.org/10.24432/C5DW2B). The [dataset page](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic) licenses the dataset under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Retrieved 29 September 2026; retain this attribution when sharing the pack.

`wdbc.data` contains 569 observations, 30 numeric features, and recorded labels M/B. Its 124,103 bytes are pinned to SHA-256 `d606af411f3e5be8a317a5a8b652b425aaf0ff38ca683d5327ffff94c3695f4a`. The fixed analyzer checks the fingerprint before interpreting the bytes. Tests also validate structural failures independently of the fingerprint.

From the repository root, install backend dependencies with `npm --prefix services/pilot ci`, then:

```sh
npm run build:pilot
npm exec --yes --package=node@22.13.0 -- node services/pilot/scripts/reproduce-wdbc.mjs
```

The checked receipt reproduces `rows=569`, `features=30`, `malignant=212`, `benign=357` with zero tolerance. It records source attribution, data manifest, recipe, observed outputs and SHA-256 fingerprints of the method source, compiled method and fixed entry script. Compiled method bytes are regenerated by the pinned compiler.

The script reads only the fixed local pack and writes its report. No provider key, database, shell supplied by a participant, external download or arbitrary code execution is involved. The report is a local self-reported receipt, not an independently signed attestation. Hosting and retaining code artifacts, reviewer independence, domain evaluation, general execution isolation and a biomedical research protocol remain separate work.
