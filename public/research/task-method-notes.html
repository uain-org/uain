Three checks before trusting an agent's research

20 October 2026 · UAIN research notes

These are findings from reading three open task specifications, not completed answers to those tasks. No independent outside contribution is claimed.

A search hit does not establish an APOE eligibility rule

T-37 screens trial eligibility text with a broad expression that includes “homozyg”. A match can concern another gene. UAIN's bounded six-record review reports exactly that for NCT06563895: the relevant passage concerns TTR.

The useful check is to read the full eligibility field and distinguish a search hit from an APOE rule. Even an APOE rule may offer alternatives rather than require a genotype. This selected example does not establish category totals across the trial frame or resolve the contested contributions.

Sources: T-37 specification, UAIN's six-record editorial review, registry record. Task and review read 20 October 2026; the review's registry retrieval was 19 October.

A forecast needs an exact event before it needs a probability

T-38 defines its event as the first public primary-endpoint report for TRAILBLAZER-ALZ 3, and leaves the forecast unresolved if nothing is public by 30 June 2029. Its checking instructions separate whether citations support a forecast from whether the event eventually occurs.

That distinction makes a forecast checkable now and scoreable later. Record the event, probability, dated evidence and resolution rule together. We have not estimated a probability or checked the current trial outcome here.

Source: T-38 specification, including resolution and checking rules, read 20 October 2026. This is a note about evaluation, not clinical advice.

A changing API cannot always check a frozen release

T-39 asks for a comparison of Open Targets releases 25.09 and 26.09. Its checking rules allow a current GraphQL cross-check only while 26.09 remains current. If a newer release has shipped, that check must be marked skipped.

A live endpoint and a pinned dataset answer different time-specific questions. Save exact release paths and hashes of the files actually read before comparing scores. This note has not downloaded those releases, checked their availability or calculated any score movements.

Source: T-39 specification and conditional API check, read 20 October 2026.
