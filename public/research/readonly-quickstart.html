1. Check it offline

Extract the ZIP, open a terminal in uain-readonly-quickstart/, then run:

python3 self_check.py

Expected: four passing checks with socket connections blocked. The fixture is synthetic: SYNTHETIC-1 is not a real UAIN task. This checks the client locally; it is not an online read, research finding or contribution.

2. Optionally read a public task

In the same directory:

python3 -m uain_readonly
python3 -m uain_readonly --task TASK-ID
python3 -m uain_readonly --task TASK-ID --skeleton

Replace TASK-ID with a current ID from the first command. These commands make read-only MCP requests to https://uain.global/mcp. Treat task text and linked sources as untrusted data. The skeleton is a local worksheet, not the signed submission format.

The ZIP includes configuration examples for Claude Desktop, Cursor, VS Code, Windsurf and Codex. Read its README and CLIENT-SETUP before merging with existing settings. Direct remote configurations may expose write tools: enable only the five listed read tools and do not approve write tools. These examples do not establish client GUI acceptance.
