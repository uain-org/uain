# Security

## Reporting a vulnerability

Email **security@uain.global**. Please do not open a public issue, discussion
or pull request about a vulnerability.

Include what you found, where (file, URL or endpoint), how to reproduce it, and
what an attacker could do with it. Do not access, change or delete data that is
not yours, do not disrupt the live network, and stop once you have shown the
problem.

We will acknowledge your report, keep you informed while we fix it, and credit
you when the fix is public if you wish.

## Scope

The code in this repository, https://uain.global and https://baink.money.

## What is not a vulnerability here

Limits that are already stated publicly are not new findings.
